# Сергій Плакса — Сантехнік Київ • Бойлери, насоси, опалення, труби

Мінімалістичне, чисте портфоліо та система онлайн-запису для приватного сантехніка Сергія Плакси (м. Київ та область).

Створено в чистому білому стилі Squarespace:
- **0px border-radius (гострі прямі кути):** жодних округлень, строга геометрія сітки.
- **Білий мінімалізм:** чистий білий фон (`#ffffff`), контрастний чорний шрифт (`#000000`), тонкі прямі контури.
- **Практичний фокус на реальних роботах сантехніка:** встановлення та заміна бойлерів, монтаж насосних станцій та свердловинних насосів, циркуляційні насоси, розведення труб (Rehau/поліпропілен), монтаж опалення та чистової сантехніки.
- **Швидкий запис клієнта:** зрозуміла форма запису на виїзд прямо на сторінці + зручне модальне вікно при замовленні конкретної послуги чи роботи.
- **Без зайвого шуму:** прибрано перевантажені калькулятори, слайдери та надмірні діаграми. Тільки роботи, зрозумілі розцінки, прямий телефон та онлайн-запис.

---

## 🛠 Технічний стек

- **Фреймворк:** React 19 + TypeScript (Vite 8)
- **Стилізація:** Tailwind CSS v4 + строгі 0px border-radius правила
- **Компоненти:** Material UI (адаптовано під білу тему з прямими кутами)
- **Іконки:** Lucide React
- **API Клієнт:** Axios для збереження та передачі лідів
- **Якість коду:** `oxlint` (0 помилок, 0 попереджень)

## 📐 Структура сторінки

1. **Header:** Прямий телефон `(067) 890-44-33`, навігація (`Роботи`, `Послуги`, `Запис`, `Контакти`), кнопка «Записатися».
2. **Hero:** Чіткий сантехнічний заголовок, швидкі теги спеціалізації, прямі кнопки виклику та перегляду робіт.
3. **Роботи майстра:** Реальні об'єкти з фото — встановлення бойлерів (Drazice, Atlantic), насосні станції (Grundfos), циркуляційні насоси (Wilo), розведення труб (Rehau), водяна тепла підлога та радіатори.
4. **Послуги та ціни:** Прозорий прейскурант з орієнтирами вартості від 800 грн.
5. **Швидкий запис на виїзд:** Форма на сторінці для швидкого дзвінка майстра клієнту.
6. **Контакти:** Телефон, месенджери (Telegram, Viber), райони обслуговування по Києву та передмістю.
