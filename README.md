# Сергій Плакса | Професійна інженерна сантехніка та монтаж під ключ

Сучасний високонверсійний односторінковий веб-додаток (Single Page Application) для портфоліо та онлайн-запису на консультацію/замір для провідного майстра-сантехніка Сергія Плакси (м. Київ та Київська область).

## 🌟 Дизайн та естетика
Проєкт виконано в чистому, технічно-вивіреному editorial-стилі, натхненному топовими архітектурними та інженерними шаблонами Tilda та Squarespace:
- **Глибока темна інженерна палітра:** фон `#0B1320`, картки `#111D33`, акцентний індустріальний синій (`#0284C7` / `#38BDF8`) та благородні відтінки міді й латуні (`#D97706` / `#F59E0B`).
- **Виразна типографіка:** заголовки з високим контрастом (Plus Jakarta Sans) та моноширинні числові показники (Space Grotesk).
- **Плавні 60fps анімації:** поява блоків при скролі на базі **Framer Motion**, ефекти наведення з підсвічуванням контурів.
- **Інтерактивне до/після порівняння:** сенсорний слайдер різниці між типовим монтажем від забудовника та інженерним вузлом Rehau/FAR.

---

## 🛠 Технічний стек
- **Фреймворк:** React 19 + TypeScript (Vite збірка)
- **Стилізація:** Tailwind CSS v4 + кастомні технічні сітки та напівпрозорі скляні поверхні (glassmorphism)
- **Компонентна бібліотека:** Material UI (MUI v6/v7) — адаптована під брендову темну тему:
  - Модальне вікно консультації/виклику (`Dialog`)
  - Локалізований український вибір дати (`DatePicker` з `@mui/x-date-pickers` та `dayjs`)
  - Валідація форм, селектори об'єктів та послуг
  - Спливаючі сповіщення (`Snackbar`, `Alert`)
- **Анімації та візуальні ефекти:** Framer Motion + `canvas-confetti` (святковий салют при успішному оформленні замовлення)
- **Іконки:** Lucide React
- **HTTP Клієнт:** Axios з обробкою таймаутів, формуванням ліда та локальним сховищем (fallback mode)

## 🚀 Запуск проєкту локально

```bash
# 1. Встановлення залежностей
npm install

# 2. Запуск локального сервера розробки
npm run dev

# 3. Збірка для production
npm run build

# 4. Попередній перегляд production збірки
npm run preview
```
